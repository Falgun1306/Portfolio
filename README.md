# Falgun Panchal — Portfolio

Modern, high-performance developer portfolio built with **React**, **Vite**, and **Tailwind CSS**. Designed with a solid dark aesthetic, dynamic typing hero section, clean project showcases with problem-solving breakdowns, and an interactive contact email form.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS (Solid dark theme, no glassy blur)
- **Icons**: Lucide Icons & Custom SVG Icons
- **Typography**: Google Fonts (Plus Jakarta Sans, JetBrains Mono)
- **Deployment Ready**: Vercel / Render
